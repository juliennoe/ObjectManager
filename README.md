# Object Manager Editor

A Unity Editor tool to help developers and artists track favorite and recently selected assets across sessions.

## ✨ Features

- 🟢 **Favorites List**: Drag and drop any asset into the green box to keep it in your favorites.
- 🟡 **Recents Tracker**: Automatically store recently selected assets when enabled.
- 🔁 **Reorderable Lists**: Use drag & drop to reorder assets in both lists.
- ♻️ **Persistence**: Automatically saves your favorites and recents between Unity sessions.
- 🧹 **Cleanup**: Automatically removes null entries (e.g., deleted or missing assets).
- 🚫 **Safe Mode Handling**: UI refreshes cleanly after exiting Play Mode to prevent display issues.

## 📦 Installation

1. Copy the script into a folder under `Assets/Editor/ObjectManagerEditor.cs`.
2. Or install via Unity Package Manager using this repository (Git URL).

## 🧠 Usage

- Open the tool from `Tools > Managers > Object Manager`.
- Use the buttons to start/stop tracking or reset lists.
- Hover over items to interact, remove, or select them.
